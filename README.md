# av.by — цена в USD (myfin.by / НБРБ)

Неофициальное дополнение для сайтов **av.by**: под выбранными блоками цены в **BYN** показывает **приблизительную сумму в US$** по курсу Национального банка Республики Беларусь.

## Как работает курс

1. Сначала запрашивается страница **myfin.by** (курс НБРБ с подсказки `nbrbUSD`).
2. Если разбор или сеть не удались — **api.nbrb.by** (`Cur_OfficialRate` для USD).
3. Значение кэшируется **~45 минут** (в расширении — `chrome.storage`, в WebView закладке — по логике скрипта / `sessionStorage` в приложении).

## Расширение Chrome (MV3)

- Файлы в корне: `manifest.json`, `background.js`, `content.js`, `content.css`.
- Установка: **Расширения** → режим разработчика → **Загрузить распакованное** → выбрать эту папку.
- Работает на `https://*.av.by/*` и `https://av.by/*`.

## Какие блоки цены обрабатываются

Скрипт ищет только узлы по селекторам (текст вида «… р.» внутри узла, включая `&nbsp;`):

| Назначение | CSS (фрагмент класса) |
|------------|------------------------|
| Основная цена в списке | `listing-item__price-primary` |
| Цена в индексной строке | `listing-index__price` |
| Цена «сверху» ленты | `listing-top__price-primary` |
| Кнопка цены на карточке | `card__price-button` |

Для каждого совпадения под блок вставляется строка **≈ … $** и подпись с курсом.

> Разметка av.by может меняться: при пропаже конвертации проверьте классы в DevTools и при необходимости добавьте селектор в `PRICE_SELECTOR` в `content.js` (и синхронно в `android-app/.../inject.js`, закладку).

## Мобильный Chrome — закладка

В папке **`mobile/`**: исходник `bookmarklet-source.js`, однострочник `bookmarklet-one-line.txt`, страница **`index.html`** с кнопкой копирования URL закладки.

## Android-приложение (WebView)

Папка **`android-app/`**: загружает av.by и подмешивает `app/src/main/assets/inject.js` (та же идея селекторов и курса).

Сборка debug APK из каталога `android-app`:

```bat
gradlew.bat assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Права и данные

Расширение запрашивает **storage** (кэш курса) и доступ к **myfin.by** / **api.nbrb.by**. Данные объявлений и аккаунт av.by **не** читаются и никуда не отправляются.

## Отказ от ответственности

Проект не связан с **AV.by**, **myfin.by** или **НБРБ**. Суммы в долларах — **ориентир** для удобства; за точные финансовые решения отвечаете вы сами.
