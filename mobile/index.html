Цена в USD на av.by в мобильном Chrome

В обычном Chrome для Android и iOS нельзя установить расширения. Вместо этого используйте закладку ниже: она выполняет тот же расчёт на открытой странице (курс с myfin.by / НБРБ).

Шаг 1 — скопируйте адрес закладки

Нажмите «Копировать», затем создайте закладку и вставьте скопированное в поле URL (не в название).

Шаг 2 — добавьте закладку

Android (Chrome): откройте меню ⋮ → «Закладки» → значок звезды или «Добавить закладку» → в поле URL вставьте скопированное, название любое (например «av USD»).

iPhone (Chrome): меню … → «Закладки» → «Изменить» / «Добавить» → вставьте в URL.

Шаг 3 — как пользоваться

  1. Откройте список объявлений, например https://cars.av.by/audi.
  2. Дождитесь загрузки цен в рублях.
  3. Откройте закладку «av USD» — появятся суммы в долларах под ценами.
  4. При подгрузке новых карточек прокрутите список и снова нажмите закладку.

На ПК удобнее по-прежнему расширение из папки avbyusd (автообновление при скролле).
