Приложение «av.by USD» (папка android-app)
==========================================

Это отдельное Android-приложение (APK), а не плагин к уже установленному APK
другого браузера. Внутри — WebView с сайтом av.by и той же логикой, что
в расширении Chrome: курс с myfin.by (НБРБ), запасной api.nbrb.by, подписи
под ценами в рублях.

Требования
----------
• Android Studio Hedgehog (2023.1) или новее
• JDK 17
• Устройство или эмулятор с Android 8.0+ (API 26+)

Сборка APK
-----------
1. В Android Studio: File → Open → выберите папку «android-app».
2. Дождитесь синхронизации Gradle (интернет нужен первый раз).
3. Build → Build Bundle(s) / APK(s) → Build APK(s).
4. Готовый файл: app/build/outputs/apk/debug/app-debug.apk
   (для подписанного релиза: Build → Generate Signed Bundle / APK).

Установка на телефон
--------------------
Скопируйте APK на телефон и откройте файл (разрешите установку из
неизвестных источников, если спросит). Запускайте «av.by USD» — откроется
cars.av.by с автоматическим показом цен в долларах.

Важно
-----
• Сайт av.by может показывать защиту (WAF) нестандартным WebView — если
  страница пустая, попробуйте обновить или открыть ссылку в обычном Chrome.
• Логику конвертации можно править в app/src/main/assets/inject.js
  (без пересборки Kotlin, если только JS меняете — всё равно нужна
  пересборка APK, чтобы assets попали в пакет).
